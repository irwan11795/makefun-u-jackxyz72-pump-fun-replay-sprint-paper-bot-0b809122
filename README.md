Steady Sniper — a deterministic momentum scalper that trades 10 SOL of paper money on a 24h pump.fun replay. It buys small, only after the tape confirms buying pressure (several buys, buy volume dominating, price up from creation but not chased to the top, still rising over the last few trades), and exits fast on take-profit, stop-loss, trailing stop, or a max hold time. One buy per mint, ever; every decision is a pure function of the event stream, so two runs agree byte for byte.

```sh
node main.ts
```
